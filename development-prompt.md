# Актуальная задача — Windows 95 Classic

Создать стандартную светлую тему для установленного VS Code 1.140.0, используя только официальный API тем. Цвета интерфейса — в colors, подсветка — в tokenColors и semanticTokenColors. Установка через обычный VSIX, включение через Preferences: Color Theme. Не подключать CSS к workbench, не открывать отладочные порты, не менять файлы приложения и не создавать копию VS Code. Предоставить необязательный пресет штатных настроек шрифтов кода и терминала, встроенного Markdown Preview и высоты вкладок. Не применять настройки автоматически. Исходники сохранить в папке проекта. Применять coder-architect. Проверить манифест, цвета, контраст и содержимое VSIX; описать ограничения официального API в README.
