# Изменения

## 1.3.1

Добавлен оригинальный значок расширения: пиксельный монитор с окном в стиле Windows 95. PNG 256 × 256 подключён через стандартное поле `icon` манифеста; сохранены SVG-исходник и скрипт воспроизводимой сборки.

## 1.3.0

Согласованы состояния вкладок, второстепенный текст, поиск, терминал, Git/diff, проверки полей и строка состояния. Расширена подсветка шести языков и семантических токенов. Добавлены 20 оригинальных файловых значков и тема Windows 95 Classic Icons. Добавлены тесты грамматик, наложений и связей значков; зафиксированы границы визуальной проверки.

## 1.1.1

Исправлен невидимый текст активной modern-вкладки. Добавлены явные пары цветов modern UI, улучшен контраст значков выбора, ANSI-текста и номеров строк.

## 1.1.0

Переход на обычную декларативную тему VS Code без CSS-загрузчика и специального запуска.
