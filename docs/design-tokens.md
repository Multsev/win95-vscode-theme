# Палитра стандартной темы

| Значение | Роль |
|---|---|
| #C0C0C0 | панели, меню, кнопки |
| #FFFFFF | редактор и поля, текст выделения |
| #000000 | основной текст |
| #000080 | активный заголовок и выбор |
| #808080 | границы и неактивный заголовок |
| #FFFFC0 | подсказки |
| #006000 | строки кода |
| #800000 | числа и ошибки |
| #555555 | комментарии |

Шрифты редактора и терминала выбираются штатными настройками. Геометрия и общий шрифт workbench не изменяются. Это поддерживаемая адаптация палитры Windows 95, а не полная реконструкция интерфейса.

## Рабочие состояния 1.3.0

| Цвет | Назначение |
|---|---|
| #4D4D4D | второстепенные подписи на серой поверхности |
| #B8CBED | выделение кода и терминала с чёрным текстом |
| #FFF4A3 | активное совпадение поиска |
| #00800012 / #00800022 | фон добавленной строки / фрагмента diff |
| #80000012 / #80000022 | фон удалённой строки / фрагмента diff |
| #FFE8E8 / #800000 | ошибка ввода, фон / текст |
| #FFF4C0 / #604000 | предупреждение, фон / текст |
| #303060 | функции и методы |
| #660066 | escape и readonly-значения |

Значки строятся на сетке 16×16: документ с загнутым углом, жёлтые открытые/закрытые папки, тёмные пиксельные метки типа файла. Они сохраняют собственные цвета на синем выборе. SVG не содержит текста, сторонних шрифтов, скриптов или внешних изображений.
