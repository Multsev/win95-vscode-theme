## Незавершённая визуальная приёмка

Computer Use вернул `Sky Computer Use service startup request failed`. Поэтому новые скриншоты окна VS Code и взаимодействия с реальным рабочим набором недоступны. Нельзя считать просмотренными все панели, hover/focus/disabled-состояния, терминал, Git/diff или автодополнение. Тесты грамматик также не заменяют работающие языковые серверы.

Для ручной приёмки:

1. Открыть несколько контрольных файлов из fixtures; проверить длинные имена, несохранённую вкладку и unfocused окно.
2. Открыть Explorer, Command Palette, Settings, поиск, уведомление и автодополнение; проверить текст, значки и focus.
3. В терминале вывести ANSI-палитру и выделить текст; проверить совпадения поиска.
4. Открыть diff из fixtures; проверить наложение поиска на изменённые фрагменты.
5. Открыть копию рабочего Markdown в штатном Preview и установленном Live/Source-редакторе, проверить длинные таблицы и сохранение.
6. Переключить другую цветовую тему и другую тему значков, затем вернуться; проверить обычный запуск VS Code.

Версия 1.1.1 сохранена для отката. Темы устанавливаются через один VSIX и выбираются обычными командами VS Code. Файлы приложения, пользовательские шрифтовые настройки и рабочие документы не менялись установкой.
