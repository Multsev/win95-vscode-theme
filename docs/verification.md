# Проверка версии 1.1.0 — 2026-10-06

Результат: стандартная декларативная тема, зарегистрированная через contributes.themes. Исполняемый код, команды подключения CSS, отладочный порт и специальный launcher удалены. Основной VS Code не модифицируется.

Проверки: npm test — 3 успешных теста; npm run build — VSIX собран; содержимое VSIX проверено: нет JavaScript/CSS/launcher и activationEvents. Контраст основного текста, выделенных пунктов, активного заголовка и цветов синтаксиса не ниже 4.5:1. В архиве только манифест, JSON темы, README, лицензия и служебные файлы упаковки.

Цветовые идентификаторы сверялись с исходниками установленного VS Code 1.140.0; Git decorations — с его встроенным расширением Git. Предыдущая живая проверка цветов выполнялась на этой версии в тестовом профиле; новые визуальные скриншоты версии 1.1.0 не сняты. Полная проверка всех языков и сторонних webview не выполнялась.

Необязательный пресет использует только штатные настройки. Он не применяется установкой темы. Геометрия интерфейса и общий шрифт workbench остаются штатными.

## Исправления версии 1.1.1

Проблема по скриншоту: белый текст на активной белой вкладке нового интерфейса. В исходниках VS Code 1.140.0 modernEditorTab.activeForeground наследуется от modernTab.activeForeground, который использует list.inactiveSelectionForeground. У темы этот цвет белый для синего выделения списков. Теперь цвета modernTab и modernEditorTab заданы явно: активная вкладка белая с чёрным текстом, неактивная серая с чёрным текстом. Hover и фон кнопок вкладки также заданы явно. Добавлены отдельные цвета modernActivityBar и surface.

Исправлены серый значок на синем фокусе палитры команд, светлый ANSI-текст на белом фоне терминала, номера строк и недоступные подписи. Идентификаторы новых цветов сверены с установленным VS Code и официальным Theme Color Reference. Явных пользовательских переопределений цвета вкладок в просмотренных settings.json не найдено.

Шесть тестов пройдены: декларативный манифест, базовые пары, официальный пресет, 27 пар состояний вкладок/панелей/выделений, все 16 цветов ANSI и остальные явно заданные непрозрачные пары foreground/background. Контраст проверяемых пар не ниже 4.5:1. VSIX 1.1.1 установлен в рабочий VS Code.

Повторная визуальная проверка окна недоступна: сервис Computer Use вернул Sky Computer Use service startup request failed. Поэтому исправление подтверждено анализом наследования и цветов, а не новым скриншотом рабочего окна.

## Версия 1.3.0

Реализованы доработка состояний, синтаксиса, терминала, поиска, Git/diff и 20 оригинальных файловых значков. Подробности — docs/audit.md. npm test: 15 пройденных проверок, 0 пропусков и 0 ошибок, включая реальную токенизацию шести языков и копии рабочего Markdown.

VSIX проверен: зарегистрированы Color Theme и File Icon Theme; все SVG присутствуют, runtime-код отсутствует. 1.3.0 установлена в рабочий VS Code. Предыдущий VSIX 1.1.1 сохранён. Полная визуальная приёмка окна не выполнена из-за недоступного Computer Use; это отдельно отмечено в аудите. Значки просмотрены в 16/32px на сером, белом и синем фоне.
