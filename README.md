# Windows 95 Classic

![Значок расширения](assets/extension-icon.png)

Версия 1.3.2. Стандартная светлая тема VS Code и согласованная тема файловых значков. Серые панели, белые активные вкладки с синей границей, тёмно-синее выделение списков, читаемая подсветка и оригинальные пиксельные значки. Разработана для VS Code 1.140.0 на macOS.

## Установка и включение

Скачайте `windows95-classic-1.3.2.vsix` из [релиза v1.3.2](https://github.com/Multsev/win95-vscode-theme/releases/tag/v1.3.2). В VS Code откройте Extensions → «…» → Install from VSIX и выберите скачанный файл. При сборке из исходников пакет находится в `artifacts/`.

В палитре команд:

1. Preferences: Color Theme → Windows 95 Classic.
2. Preferences: File Icon Theme → Windows 95 Classic Icons.

Выбор цвета и значков разделён самим VS Code. Обе темы находятся в одном расширении. Установка не меняет пользовательские настройки. Если Windows 95 Classic уже выбрана, обновление заменяет её цвета; при старом отображении выполните Developer: Reload Window.

CLI:

```sh
"/Applications/Visual Studio Code.app/Contents/Resources/app/bin/code" --install-extension artifacts/windows95-classic-1.3.2.vsix --force
```

После установки VS Code запускается обычным способом. Расширение декларативное: исполняемого кода, фоновых процессов, отладочного порта и CSS-инъекции нет.

Выделение текста в карточках расширений и полях интерфейса использует светло-голубой фон: чёрные заголовки остаются читаемыми. Для общего выделения текста официальный API предоставляет `selection.background`, без отдельного `selection.foreground`.

## Что доработано

- Классические и новые вкладки: активное, неактивное, unfocused, hover и modified состояния.
- Вспомогательные подписи и границы: спокойная серая иерархия с читаемым контрастом.
- Подсветка JavaScript/TypeScript, Python, JSON, YAML и Markdown; семантические типы и свойства; ссылки, цитаты, inline code и diff.
- Жёлтые совпадения поиска, голубое выделение кода и терминала, контрастные значки автодополнения.
- Git-статусы и diff: зеленоватые добавления, красноватые удаления, отдельные контуры изменённых фрагментов.
- Ошибки, предупреждения, remote и hover состояния строки состояния и проверка полей ввода.
- 20 оригинальных SVG-значков 16px: файлы и папки, Markdown, JS/TS, Python, JSON/YAML, конфигурация, CSS, shell, Git, изображения, PDF и архивы. Стрелки раскрытия папок сохранены.

В карточке расширения используется оригинальный пиксельный монитор с надписью «95»: `assets/extension-icon.png` (256 × 256). Исходник — соседний SVG; сборка рисунка — `scripts/render-extension-icon.cjs`.

Значки — собственные рисунки в стилистике эпохи, а не копии ресурсов Microsoft. Предпросмотр: `artifacts/icon-preview.png`.

## Шрифты и дополнительные настройки

В `presets/settings.json` находится необязательный пресет штатных настроек: Courier New 14px для редактора и терминала, межстрочный интервал кода 20px, compact tabs, custom title bar и Microsoft Sans Serif 14px для встроенного Markdown Preview.

Переносите только нужные ключи в существующий объект User Settings JSON. Не заменяйте файл настроек целиком. Пресет не включается автоматически; общий шрифт интерфейса не изменяется.

## Откат

Выберите другую Color Theme и File Icon Theme. Локально прежний VSIX 1.1.1 сохранён в `artifacts/`; он не включён в публикацию на GitHub. Если меняли настройки из пресета, верните только эти значения. Исходные документы не изменялись.

## Разработка

```sh
npm ci
npm test
node scripts/render-extension-icon.cjs
node scripts/generate-icons.cjs
node scripts/render-icon-preview.cjs
npm run build
```

Node.js 22+ нужен только для сборки и проверки. `package.json` регистрирует две темы; `themes/windows95.json` содержит цвета, TextMate и semantic token rules; `icons/windows95-icon-theme.json` — связи файлов и значков; `icons/images/` — SVG; `scripts/generate-icons.cjs` — воспроизводимый исходник рисунков; `tests/` — проверки контраста, наложений, грамматик и связей значков; `fixtures/` — документы приёмки; `docs/` — аудит и ограничения.

Интеграционные тесты используют грамматики установленного VS Code по пути `/Applications/Visual Studio Code.app/Contents/Resources/app`. Для другого пути задайте `VSCODE_APP`. При отсутствии приложения эти тесты пропускаются. Для локальной проверки рабочего документа тест читает только его копию `.runtime/review.md`; она не входит в Git, VSIX и архив исходников.

Цвет добавляйте в `themes/windows95.json` после проверки его идентификатора. Новый значок добавляйте в генератор, затем пересоздавайте SVG и маппинг. Проверка контраста 4.5:1 относится к обычному тексту; она не гарантирует различимость всех видов нарушений цветового зрения и всех сторонних webview.

## Границы проверки

Сводка — `docs/audit.md`. Автоматические проверки выполнены; значки визуально просмотрены на трёх фонах. Полная визуальная приёмка рабочего окна не завершена из-за недоступного сервиса Computer Use. Это не заменяется проверкой JSON. Markdown Live/Source, динамика таблиц, семантическая подсветка языковых серверов и все интерактивные состояния требуют отдельной живой проверки.

Геометрия, скругления и общий шрифт workbench остаются штатными. Нативные диалоги macOS и изолированные webview сторонних редакторов тема не переоформляет. В старом экспериментальном комплекте 1.0.0 CSS следовало отключить до перехода на стандартную тему; при разработке он использовался только в тестовом профиле.

Официальные справочники: [Color Theme](https://code.visualstudio.com/api/extension-guides/color-theme), [Theme Colors](https://code.visualstudio.com/api/references/theme-color), [File Icon Theme](https://code.visualstudio.com/api/extension-guides/file-icon-theme).
